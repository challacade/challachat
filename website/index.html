Capture and display any livestream chat in a custom overlay.

No cloud, all local. Completely free and open source!

Works with Any Streaming Software

Compatible with OBS Studio, Streamlabs, and any streaming software that supports Browser sources.

🌐 Cross Platform

Windows, macOS, and Linux builds available as both installer and portable. Works with OBS, Streamlabs, and any streaming software via Browser Source.

⚡ Multi‑Stream Capture

Supports YouTube, Twitch, and Kick with up to 10 simultaneous connections. Messages stream instantly to your overlay via local SSE.

🔒 Secure & Private

No telemetry, no cloud - all processing runs locally on your machine. Your chat data never leaves your computer.

🎨 Full Customization

Theme presets, custom fonts, color pickers, and a live preview. Sound effects, a built‑in music player, profanity filter, and more - all from one admin panel.

  1. Download & install ChallaChat - Direct Windows Installer or View Latest Release
  2. Launch the program, paste-in any livestream URL
  3. Once connected, create a Browser source using the provided localhost.
  4. Adjust the overlay appearance and sound settings to fit your livestream.
