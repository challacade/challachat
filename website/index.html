ChallaChat

Capture and display any livestream chat in a custom overlay.

No cloud, all local. Completely free and open source!

Download on GitHub View latest release

Works with Any Streaming Software

Compatible with OBS Studio, Streamlabs, and any streaming software that supports Browser sources. Try the live demo!

🌐 Cross Platform

Portable Windows app today with no installation required. Works with any streaming software via Browser Source. macOS and Linux support planned.

⚡ Ultra‑Low Latency

Built‑in chat capture connects directly to YouTube for instant message display and minimal CPU usage—no browser extensions required.

🔒 Secure & Private

Digitally signed releases, no telemetry, and everything runs locally—your chat data never leaves your computer.

🎨 Full Customization

Dark, Light, and Transparent themes with adjustable colors, fonts, animations, and notification sounds (with volume control).

  1. Download & install ChallaChat — Direct or View Latest Release
  2. Launch the program, paste-in any livestream URL
  3. Once connected, create a Browser source using the provided localhost.
  4. Use the Interact feature to adjust the overlay settings
